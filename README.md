<h1 align="center">云哨·边缘智枢</h1>

<p align="center"><strong>让边缘看见异常，让协同抵达现场，让智能推动改进。</strong></p>

“云哨·边缘智枢”是一套面向园区、工厂、企业、校园等公共场所的云边端协同智能平台，集异常事件感知、智能数据分析、告警消息推送和对外 MCP 服务于一体。

团队自主研发的垂直领域计算机视觉算法，可部署在搭载华为、瑞芯微等国产芯片的边缘设备上。边缘设备分析摄像头采集的实时视频流，识别异常事件；经过算法处理的视频流可实时传输至监控大屏，检测到的事件则上传至平台数据库。

用户可以在监控大屏查看各边缘设备的运行状态、所在位置和实时画面，也可以在历史告警中查看事件截图、地点和时间。告警可推送至 PWA、Android App 和 iOS App，用户点击通知即可进入事件详情，了解情况并前往处理。

平台内置 MCP 服务，可接入各类 AI Agent 客户端。用户可以设置定时任务，让 Agent 分析当日异常事件的分布，并根据分析建议采取后续措施，降低类似事件再次发生的概率，或为底层算法优化提供参考。

## 项目亮点

1. **云边端协同**：边缘设备连接摄像头，在本地运行计算机视觉算法，实时分析视频流并识别异常；云端平台统一管理设备状态与位置，汇聚并存储异常事件；监控大屏、手机客户端和 AI Agent 分别承担实时查看、告警接收与处置、事件分析等工作，形成从边缘感知、云端汇聚到终端响应的协同链路。
2. **用户友好**：监控大屏集中展示设备状态、位置和实时画面，历史告警保留事件截图、地点和时间。用户无需持续盯守屏幕，收到手机客户端通知后即可进入事件详情并前往处理。
3. **AI 友好**：平台通过 MCP 向 AI Agent 开放事件分析能力。Agent 可以按计划分析事件的发生时段和高发点位，为巡查安排、现场处置和算法优化提供建议。

## 首发场景：消防通道占用检测

消防通道占用适合作为首发场景：摄像头点位相对固定，检测区域明确，事件发生后需要及时通知和现场处置，也便于验证从边缘识别到业务处置的完整链路。建议先围绕单个点位跑通闭环，再逐步扩展到更多通道和设备。

### 最小业务闭环

以下流程可作为首发版本的业务范围和验收依据：

1. **接入点位**：选择能够覆盖消防通道的摄像头，在平台登记设备、位置和对应画面，并在边缘侧配置检测区域。
2. **识别并生成事件**：边缘设备识别通道区域内的车辆或其他占用物；当占用持续达到设定时长后，生成异常事件，并附带发生时间、设备与地点信息及事件截图。
3. **推送告警**：平台接收并保存事件，在告警列表中展示，同时向相关人员的手机客户端发送通知。用户点击通知即可进入事件详情。
4. **现场处置并反馈**：处置人员根据地点信息前往现场，确认并清理占用；在详情页记录处理结果、处理人和处理时间，必要时补充现场照片。建议支持“待处置”“处理中”“已解除”等状态，并允许将误报标记出来。
5. **复盘与改进**：平台保留事件及处置记录。管理人员查看重复发生的点位和时段，并通过 MCP 让 AI Agent 定期分析事件分布，形成巡查安排或进一步优化建议。

## 设计哲学

云哨的设计从真实事件处置出发：让计算发生在合适的位置，让信息在需要的时候抵达相关人员，再让数据帮助下一次做得更好。

- **感知靠近现场**：将视觉算法部署在边缘设备上，就近分析实时视频；只把业务所需的事件信息汇聚到云端，配合处理后的视频流满足实时查看需求。
- **告警服务于行动**：平台围绕事件组织设备、位置、时间和截图等信息，通过消息通知把用户从被动盯屏带到及时响应，并为现场处置保留记录。
- **智能持续改进**：MCP 将事件数据连接到 AI Agent，让分析结果能够辅助巡查、处置和算法优化；AI 提供建议，人员结合现场情况作出判断和行动。
