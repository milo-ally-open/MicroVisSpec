# 告警查询 MCP 任务书

> 状态：草案，待团队确认；属于后续能力，不是当前全栈联调阶段的默认交付
> 依据：[PRD 0.5](../Analysis/PRD.md)、[平台技术规格草案](../Analysis/SPEC.md)
> 首版范围：通过 MCP 只读查询模拟告警

## 1. 目标

让获准使用的 AI 客户端通过 MCP 查询平台中的告警信息，便于演示自然语言检索和摘要。首版只读，不替代现有网页告警处置界面，也不连接视觉模型。

## 2. 当前基线

- 当前网页原型使用浏览器 `localStorage`，没有后端 API 或共享存储。
- 技术规格中的告警 API 是候选草案，接口和字段尚未获团队确认或实现。
- 仓库没有已完成、可供本任务直接接入的 MCP 告警功能。
- 当前项目只有单个模拟点位和模拟事件；不得把它描述为真实监控结果。

## 3. 状态与前置条件

本任务书当前仅供团队讨论。开始实现前需满足：

1. 团队确认模拟告警全栈联调范围。
2. 告警 API 和事件字段已确认并由后端实现；MCP 不直接依赖网页 `localStorage`。
3. 确认 MCP 客户端、运行位置及连接方式；在此之前不决定部署形态。
4. 明确允许哪些使用者访问演示数据；若服务离开本机或可信演示环境，先定义认证与授权。

## 4. 首版范围

只提供两类只读工具：

1. **查询告警列表**：支持按已确认的告警状态筛选；返回数量应受限，具体限制与后端 API 一起确定。
2. **查看告警详情**：按事件编号返回单条事件的必要字段；事件不存在时返回明确结果。

返回内容至少保留事件编号、类型、点位、发生时间、处置状态和来源标记。证据图只返回已确认的引用信息，不把本机文件路径、令牌或模型权重交给 AI 客户端。

## 5. 不在本任务范围

- 创建告警、修改处置状态、删除记录或执行其他写操作。
- 直接访问数据库、浏览器存储或模型文件。
- 实时视频、摄像头控制、算法推理、通知推送和生产级运维。
- 未经确认的远程公开访问、生产数据访问和完整用户/租户权限系统。
- 因 MCP 引入独立微服务集群；优先复用告警应用的业务和数据访问边界，具体部署方式待环境确认。

## 6. 执行步骤

1. 确认目标 MCP 客户端、运行位置、传输方式和本地/远程访问边界。
2. 对齐 MCP 工具输入输出与已批准的告警 API；需要的字段若 API 缺少，应先更新并确认 SPEC。
3. 实现只读工具适配层，通过平台告警服务/API 查询，不复制业务数据或状态规则。
4. 处理无结果、未知状态、无效参数、事件不存在及后端不可用等情况，并返回清楚且不泄漏秘密的错误信息。
5. 在约定的 MCP 客户端中演示查询，并确认工具无法修改告警。

## 7. 验收标准

- 获准的 MCP 客户端可以查询模拟告警列表，并能按已支持的状态筛选。
- 可以按有效事件编号取得详情；无效编号和无效参数得到明确、可恢复的响应。
- 列表结果有数量上限；默认值和最大值由接口规格记录，不允许无界返回。
- MCP 返回的来源字段清楚区分模拟数据；不能把模拟事件说成真实算法告警。
- 工具只能读取；不能创建、更新或删除告警。通过同一后端 API/服务读取，不绕过应用层访问数据库。
- 失败响应不会暴露 API 密钥、令牌、绝对本机路径或模型权重内容。
- 若使用远程连接，须先完成团队批准的认证/授权方案；否则只在约定的本地或可信演示环境验收。

## 8. 责任与未决事项

- 负责人：用户（平台服务和 MCP 接入）；涉及告警语义时与队友确认。
- 依赖：已稳定的告警 API、目标 MCP 客户端及运行环境。
- 待决：本地还是远程运行；传输方式；MCP 客户端；认证要求；列表分页/数量上限。
- MCP 不负责 YOLO 模型生命周期。任何模型权重、令牌和本机路径不得加入、提交或推送到代码仓库。

## 9. 完成定义

完成首版只读查询、错误处理、来源标记及目标客户端演示，并记录运行方式和未覆盖的安全边界后，任务才算完成。任何写操作或远程生产访问都需要独立规格和批准。
