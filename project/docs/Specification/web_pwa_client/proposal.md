# 提案：Web 与 PWA 首发工作台

> 状态：可实现<br>
> 路径：跨边界/高风险<br>
> 负责人：Web 客户端<br>
> 上游合同：[PRD](../../Analysis/PRD.md)、[总 SPEC](../../Analysis/SPEC.md)、[系统结构](../../Design/STRUCTURE.md)；课堂行为：[课堂行为规格](../classroom_behavior_detection/spec.md)

## 背景与问题

2026-10-20 本机演示反馈：登录接口拒绝用户名/密码时，API 客户端把 401 统一显示为“登录状态已失效”，导致用户误以为会话或环境故障。修复只调整登录失败文案并增加回归验证；本机演示账号使用便于输入的测试密码，凭据留在仓库外私有文件。

`project/src/clients/web` 已有 Vue 3、Vite、TypeScript、路由、基础 PWA 壳与更新提示，但页面为占位内容、API 模块为空。首发业务已切换为教室行为检测，需要形成设备配置、教室监控、规则设置、异常事件处置和 PWA 通知工作台。

## 目标与成功观察

2026-10-20 工作台视觉优化：针对现有 8–12px 小字、图标风格不一、弱层级、窄屏表单拥挤的问题，统一深绿导航/浅色内容、卡片/表单/表格和键盘焦点样式。概览日期问候随上海时区更新，统计标题跟随选定范围；登录页提供密码显示切换。沿用现有 API、数据与账号规则，不加入模拟的业务指标或外部字体依赖。验收覆盖登录/注册和全部工作台页面的桌面、平板及 360/390px 窄屏布局。

- 用户登录后只看见自己账号的数据，可以完成设备、教室视频和算法配置。
- 三类行为规则默认关闭；仅命中启用规则的行为进入事件与告警页面。
- 桌面端可查看实时监控与基础分析；手机端可用 PWA 查看事件、处置和订阅通知。
- API 失败、过期证据、设备离线、推流故障、未启用告警和空数据均有清晰状态。

## 范围

### 本次包含

- 注册、登录、登出、改密、CSRF/会话处理和账号路由守卫。
- 概览、设备/摄像头列表与详情、教室实时监控、YOLO11n 行为规则配置、事件列表/详情/处置、统计页。
- `hand-raising`、`reading`、`writing` 各自启用状态、阈值/持续条件/等级校验；新配置明确展示“全部关闭”。
- PWA 安装引导、应用壳离线、服务工作线程通知、点击通知后鉴权跳转和推送授权 UI。
- 与五个首发微服务的同源 API 客户端、加载/空/错误/冲突/离线状态。

### 本次不包含 / 保持不变

- 消防通道场景、MCP 管理、原生移动客户端。
- 离线缓存 API 数据、视频流、截图、用户信息或 Push 订阅。
- 未登录时的事件/截图访问；推送 payload 不含截图或完整课堂行为载荷。
- 学生身份/成绩/专注度页面、历史普通检测回放。

## 现状依据与约束

- 现有入口：`src/main.ts`、`src/router/index.ts`、`src/api/index.ts`、`src/App.vue`、`src/style.css`；已有 manifest、图标、service worker 插件配置。
- 技术栈与 API 归属以 `package.json`、`vite.config.ts` 和全局技术 SPEC 为准。所有浏览器 API 同源 `/api/v1`，由 Nginx 路由；浏览器不直连服务端口或 MediaMTX 管理 API。
- 安全约束：Cookie 会话、CSRF、账号内对象校验，证据经 event-service 鉴权读取，RTSP 凭据不进入客户端。
- 未确认视觉稿时采用响应式的中性管理台风格，不改变 PRD 承诺。

## 备选方案与建议

| 方案 | 收益 | 成本/风险 |
|---|---|---|
| Vue 单页应用、按域拆 API 模块、共享响应式布局 | 复用现有工程，桌面监控和手机 PWA 共用业务页面 | 实时流和 PWA 浏览器差异需分别处理 |
| 另建 Web 与 PWA 两个应用 | 可独立发布 | 认证、页面与推送逻辑重复 |

建议：保留单一 Vue 应用，以响应式断点适配桌面/手机；桌面监控大屏不强行放入手机导航。

## 影响面、依赖与风险

- 依赖 auth、device、event、media、push API 实现及 Nginx same-origin/HTTPS 部署。
- WebRTC/HLS 的实际 URL 和浏览器兼容需媒体服务及园区网络联调。
- Push 依赖 VAPID、用户主动授权、设备订阅关联和有效 service worker；权限拒绝时事件列表仍可用。
- 模型文件缺失不会阻止构建 UI，但设备状态应显示模型未就绪；不得用演示数据伪装真实边缘结果。
