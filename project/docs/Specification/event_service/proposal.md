## 目标

拥有通用事件、证据、处置、账号内查询统计和通知 outbox。

## 范围

MQTT 接入/应用 ACK、证据生命周期、查询处置统计及 event.created。

## 边界

设备资产主数据、推送投递及算法检测逻辑。
