# 云哨边缘智枢产品需求文档（PRD）

> 状态：首发范围已明确，本文仍为产品需求草案；具体技术配置见[架构设计](../Design/STRUCTURE.md)。

## 1. 产品背景

云哨边缘智枢面向园区、工厂、企业、校园等场所，连接边缘设备、摄像头和视觉算法，将设备状态、实时视频、异常事件、告警处置和通知纳入同一平台。平台面向多种场所和事件类型；消防通道占用检测是首发落地场景，不构成平台的业务限制。

用户需要以个人账号管理自己名下的数据，并能查看设备和视频、查询异常事件、处理告警以及接收手机实时通知。平台还规划智能数据分析大屏；MCP 能力将在系统稳定后设计。

## 2. 用户与使用场景

### 用户

- **平台用户**：使用个人用户名和密码注册、登录，管理自己账号下的设备、视频、事件、分析数据和通知；用户本人可作为事件处置人。

### 核心场景

1. 用户注册、登录并维护自己的账号。
2. 用户手动登记边缘设备，填写设备 IP、名称、位置等信息，查看设备及其摄像头、算法运行情况和参数。
3. 用户在实时监控界面查看已接入的视频流及设备状态。
4. 用户查询自己账号下的通用异常事件，查看事件时间、位置、危险等级、截图等信息，并记录处置过程。
5. 事件发生后，用户在已订阅的 PWA 上收到自己账号下的实时告警通知，并可跳转到事件详情。
6. 用户通过智能数据分析大屏查看自己账号下的事件与设备统计。

## 3. 用户故事

- 作为平台用户，我想用用户名和密码注册、登录，以便管理属于自己账号的数据。
- 作为已登录用户，我想通过旧密码验证后修改密码，并确认新密码，以便安全地维护账号。
- 作为平台用户，我想手动填写设备 IP、名称和位置登记边缘设备，以便把设备纳入账号管理。
- 作为平台用户，我想查看设备实时状态、关联摄像头、部署算法及算法参数，以便了解设备当前运行情况。
- 作为平台用户，我想查看摄像头实时画面，以便远程了解现场情况。
- 作为平台用户，我想按条件查询异常事件并查看截图、地点、时间和危险等级，以便判断事件情况。
- 作为平台用户，我想将事件标记为待处置、处理中、已解除或误报，并记录处理人、时间和结果，以便追踪处置过程。
- 作为平台用户，我想在手机 PWA 收到账号范围内的实时告警通知，并从通知进入事件详情，以便及时响应。
- 作为平台用户，我想查看账号范围内的事件与设备数据可视化，以便了解整体运行情况和变化趋势。

## 4. 范围

### 首发范围

- 用户名和密码注册、登录、账号密码修改。
- 按个人用户账号隔离设备、事件、通知和分析数据。
- 手动登记边缘设备，至少包含 IP、名称和位置。
- 首发边缘硬件采用 Atlas 200I DK A2；首发试点仍先围绕单个消防通道点位验证，再扩展至最多 12 路活动视频通道。
- 设备状态、摄像头、运行算法和算法参数的查看；参数配置能力按设备和算法能力逐步实现。
- 实时监控界面。
- 通用异常事件的接收、去重、查询、详情查看和处置记录。
- 事件截图暂存在后端服务器，自上传成功起可查看 24 小时；过期后详情仍保留事件与处置信息，并明确提示截图已过期。
- PWA Web Push 实时告警通知，通知内容包括地点、危险等级、时间等必要信息，并支持跳转事件详情。
- 智能数据分析大屏首发提供基础统计，可切换今天、近 7 天和近 30 天；展示设备总数与在线数、事件与未闭环数量、事件趋势、危险等级、事件类型、高发位置和处置状态。

### 后续阶段

- MCP 服务：待系统稳定后定义工具、权限和调用审计范围。
- Android、iOS、Harmony 等原生客户端及其推送能力属于后续阶段；首发推送客户端为 PWA。
- 更多算法、设备型号和场所类型的接入。

### 非目标

- 平台不限定为消防通道占用检测；该检测仅用于首发验证。
- 当前阶段不设计 MCP 服务的具体工具与接口。
- 当前阶段不引入对象存储桶；截图暂存于后端服务器。
- 当前需求不要求用 SSH 作为设备业务通信通道；SSH 仅用于设备状态运维。

## 5. 产品约束、假设与风险

### 已确认产品约束

- 设备、事件、通知及可视化数据归属于当前登录用户账号。
- 用户需能手动登记设备的 IP、名称和位置。
- 用户需能通过浏览器查看实时视频；视频不可播放时应提供可用的回退体验。
- 首发手机告警客户端为 PWA，告警通知需关联事件详情。
- MCP 能力不属于当前首发设计范围，待系统稳定后再定义。
- 首发事件截图由平台保存并在上传后 24 小时内于详情页查看；过期后不再返回图片，事件及处置记录仍可查看。

### 假设与风险

- [风险] 截图存储在单台后端服务器；24 小时内若服务器或文件卷故障，截图可能丢失，详情页须明确显示证据不可用。
- [风险] 浏览器实时视频播放受网络连通性和编码兼容性影响；回退播放方式可能增加延迟。
- [风险] 设备通过 IP 登记不代表平台始终可直接访问设备；网络变化、NAT 和设备身份认证需要在技术设计中处理。

## 6. 成功指标

首发按**完整业务闭环**验收，暂不设定量化目标值。验收需覆盖账号登录、设备登记与状态查看、实时视频查看、事件接收与查询、事件处置记录、PWA 告警通知及其详情跳转，以及基础数据分析大屏展示。

## 7. 首发决策

- 首发按完整业务闭环验收，暂不设置事件处理时效或推送送达率的量化门槛。
- 首发 Atlas 200I DK A2 视频配置、单园区试点网络与观看容量由[架构设计](../Design/STRUCTURE.md)确定。
- 截图保存 24 小时；基础统计图表与时间范围按本节首发范围交付。
